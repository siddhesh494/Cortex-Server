API endpoint - /chat

Senario
1) when click on the new chat and the first message send the request body will look like 
    {
        message:""
    }
    In this senarion it will create an new session in chatSession with the details as 
    {
        id, user_id, chat_session_name, summary, recent_messages, created_at, updated_at
    }
    chat_session_name will be the short name for the username and will get that from LLM (create an skeleton function for this)
    at start summary will be just an empty object
    Recent message will be an array where max length is 10 and it will contain user, llm message


2) when sending message on the excisting  chat the request body will look like
    {
        message: "",
        chatSessionId: "" (uuid)
    }
    In this senario it will query the exsisting session and update the recentMessage and 
    the summary if the recent messages length become more that length 10
